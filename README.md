# Still Here.

> "Some storms become the people who survive them."

A cinematic, scroll-driven birthday tribute — built with React Three Fiber,
GSAP ScrollTrigger, and Tailwind v4.

See [`birthday.md`](./birthday.md) for a running build log: what's done, what's
verified, and what's next.

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Deploys automatically to GitHub Pages via `.github/workflows/deploy.yml` on
every push to `main`.
